# JP02 legislative snapshots

Partial original-language collection: 314 editions, including 304 newly covered laws and10 additional newer editions. Earlier editions are retained. Each page preserves its dated source metadata. Not a complete national corpus, complete source reproduction, translation or certification of legal force. Figures, tables and formulas are omitted with source-location notices.

## Append validated batches

Use `python scripts/append-verified-batch.py <private-batch-directory>` for pinned official API receipts and `python scripts/validate-batch.py <private-batch-directory>` before publication. Raw sources remain outside this repository. Existing law pages are not regenerated. UI languages do not translate legal wording.
